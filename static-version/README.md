# النسخة الثابتة — HTML / CSS / JavaScript

هذه نسخة مستقلة بجانب نسخة React الأصلية. **لا تلمس** `frontend/` ولا `backend/`، ولا تعتمد على Node أو قاعدة بيانات أو أي خادم تطبيقات.

## التشغيل

الطريقة الأسهل: افتح `index.html` مباشرة في المتصفح.

أو شغّل خادمًا ثابتًا بسيطًا من جذر المشروع:

```bash
cd static-version
npx --yes serve .
```

ثم افتح `http://localhost:3000`.

> تعمل الصفحات من `file://` أيضًا لأن البيانات محمّلة عبر وسم `<script>` عادي وليس عبر `fetch`.

## الملفات

| المسار | الوصف |
| --- | --- |
| `index.html` | الصفحة الرئيسية |
| `departments.html` | التخصصات السبعة عشر مع تصفية |
| `department.html?slug=...` | تفاصيل تخصص واحد |
| `subjects.html` | نظرة مبسّطة على المواد الدراسية |
| `about.html` | عن المجمع |
| `admission.html` | شروط القبول والخطوات |
| `apply.html` | نموذج تقديم تجريبي بنمو تحقّق ومؤشر اكتمال |
| `news.html` | الأخبار |
| `gallery.html` | معرض الصور مع عارض ضوئي |
| `contact.html` | قنوات التواصل |
| `assets/css/style.css` | التصميم كاملًا (نفس لوحة الألوان الأصلية) |
| `assets/js/data.js` | بيانات التخصصات الحقيقية + بيانات عرض للأخبار والأسئلة |
| `assets/js/app.js` | كل التفاعلات: القائمة، التمرير، الظهور التدريجي، الميل، العدّاد، التصفية، النموذج |

## ما الذي تعمل هنا؟

- تصميم RTL عربي متجاوب لسطح المكتب والتابلت والهاتف.
- حركات خفيفة: شريط تقدّم القراءة، ظهور العناصر عند التمرير، ميل البطاقات، أزرار مغناطيسية، عدّادات متحركة، نقش ثلاثي الأبعاد بـ CSS في الهيرو (النسخة الحقيقية تستخدم WebGL عبر Three.js).
- نموذج التقديم يتحقق من المدخلات محليًا ويعرض نسبة الاكتمال، لكنه **لا يرسل أي شيء إلى خادم**. النسخة الكاملة هي التي تحفظ الطلبات.
- بيانات التخصصات وأوصافها مأخوذة من `backend/src/db/real-departments-data.js` دون تعديل.

## ما الذي لا يوجد في هذه النسخة؟

- لا يوجد React، ولا بناء (build)، ولا حزم npm مطلوبة للتشغيل.
- لا يوجد backend، ولا تسجيل دخول، ولا قاعدة بيانات، ولا رفع ملفات، ولا CSV.
- لا توجد WebGL حقيقية؛ الهيرو هنا مؤثر CSS فقط بديل خفيف.

## العلاقة مع المشروع الأصلي

المشروع الأصلي في `frontend/` و`backend/` باقٍ كما هو تمامًا. هذه النسخة مجرد مجلد إضافي للعرض والتعلّم، ويمكن حذف مجلد `static-version/` بالكامل دون أي أثر على التطبيق الأصلي.
