# النسخة الثابتة — HTML / CSS / JavaScript

هذه نسخة مستقلة بجانب نسخة React الأصلية. **لا تلمس** `frontend/` ولا `backend/`، ولا تعتمد على Node أو قاعدة بيانات أو أي خادم تطبيقات.

## التشغيل

الطريقة الأسهل: افتح `index.html` مباشرة في المتصفح.

أو شغّل خادمًا ثابتًا بسيطًا من جذر المشروع:

```bash
cd static-version
npx --yes serve .
```

ثم افتح `http://localhost:3000`.

> تعمل الصفحات من `file://` أيضًا لأن البيانات محمّلة عبر وسم `<script>` عادي وليس عبر `fetch`.

## ما الذي تعمل هنا؟

- تصميم RTL عربي متجاوب لسطح المكتب والتابلت والهاتف.
- حركات خفيفة: شريط تقدّم القراءة، ظهور العناصر عند التمرير، ميل البطاقات، أزرار مغناطيسية، عدّادات متحركة، نقش ثلاثي الأبعاد بـ CSS في الهيرو (النسخة الحقيقية تستخدم WebGL عبر Three.js).
- نموذج التقديم يتحقق من المدخلات محليًا ويعرض نسبة الاكتمال، لكنه **لا يرسل أي شيء إلى خادم**. النسخة الكاملة هي التي تحفظ الطلبات.
- بيانات التخصصات وأوصافها مأخوذة من `backend/src/db/real-departments-data.js` دون تعديل.
- شريط الاعتماد يظهر في الرئيسية وصفحة «عن المجمع»، ونصوصه قابلة للتعديل من ملف `data.js`؛ النسخة الكاملة تحفظها في قاعدة البيانات وتعدّلها من لوحة التحكم.
- أعداد الطلاب في `studentCounts` داخل `data.js` أرقام توضيحية لإظهار الشكل؛ التعديل الفعلي يتم لكل تخصص من صفحة «أعداد الطلاب» في لوحة التحكم بالنسخة الكاملة، ويُحسب الإجمالي تلقائيًا.
- صفحة المواد تعرض الـ69 مادة الحقيقية مع عدد الحصص الأسبوعية، ويمكن تصفية القائمة حسب الصف ونوع المادة (نظرية/عملية).
- المعرض يحتوي ستة أقسام: النظري، العملي، الأقسام، المسابقات، الزيارات الميدانية، والأنشطة. الأقسام الأربعة الأخيرة تستخدم صورًا بديلة إلى حين رفع الصور الرسمية.

### تحديث بيانات المواد

إذا تغيّرت الخطة الدراسية في `backend/src/db/real-subjects-data.js`، شغّل من جذر المشروع:

```bash
node static-version/tools/generate-subjects.cjs
```

هذه الخطوة للصيانة فقط؛ تشغيل الموقع الثابت لا يحتاج Node.

### تحديث الصور والشعارات

النسخة الثابتة تستخدم نسخة محلية من الأصول داخل `assets/public/`. بعد رفع ملفات جديدة إلى `frontend/public/assets`، شغّل من جذر المشروع:

```bash
node static-version/tools/sync-assets.cjs
```

### ملفات مؤقتة بانتظار رفعها من المجمع

- شعارا الاعتماد: `frontend/public/assets/img/accreditation/ministry-industry.svg` و`productivity-authority.svg` (تُنسخ تلقائيًا إلى `assets/public/img/accreditation/`).
- صور الأقسام والمسابقات والزيارات والأنشطة تحت `frontend/public/assets/img/gallery/`.
- الصياغة النهائية الدقيقة للرؤية والرسالة والاعتماد؛ النصوص الحالية مستعادة تقريبيًا من صور أُرسلت للمشروع.

## ما الذي لا يوجد في هذه النسخة؟

- لا يوجد React، ولا بناء (build)، ولا حزم npm مطلوبة للتشغيل.
- لا يوجد backend، ولا تسجيل دخول، ولا قاعدة بيانات، ولا رفع ملفات، ولا CSV.
- لا توجد WebGL حقيقية؛ الهيرو هنا مؤثر CSS فقط بديل خفيف.

## العلاقة مع المشروع الأصلي

المشروع الأصلي في `frontend/` و`backend/` باقٍ كما هو تمامًا. هذه النسخة مجرد مجلد إضافي للعرض والتعلّم، ويمكن حذف مجلد `static-version/` بالكامل دون أي أثر على التطبيق الأصلي.
